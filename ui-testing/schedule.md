# 定时任务

> 把 UI 自动化流程挂到 cron 定时执行——夜间回归、每日冒烟不用人守着点。

UI 定时任务与[接口测试的 CI/CD 定时任务](../integration/ci-cd.md)**完全独立**（独立接口 `/api/ui/schedule`、独立任务列表），专门用于调度 UI 自动化流程。

![UI 定时任务](/screenshots/zh/ui_schedule.png)

## 创建定时任务

进入 **UI 自动化工作台 → 定时任务**，点击创建，填写：

| 字段 | 说明 |
|------|------|
| 任务名称 | 必填，用于列表识别 |
| 选择流程 | 必填。按 **项目 → 模块 → 流程** 树形勾选，支持项目/模块级三态全选（半选 = 部分选中） |
| Cron 表达式 | 必填。标准 cron 格式，表单提供常用频率快捷模板，也可手动输入 |
| 通知方式 | 执行结果推送渠道（如企业微信机器人） |
| 通知地址 | 对应渠道的 webhook 地址 |
| 失败时通知 | 勾选后仅执行失败才推送 |
| 成功时通知 | 勾选后执行成功也推送 |

## 任务列表

每条任务展示：任务名、包含的流程、cron 表达式、通知配置。可随时**启用 / 暂停**任务，暂停后到点不再触发。

## 典型用法

- **夜间回归**：每天凌晨 2 点跑一遍核心流程（`0 2 * * *`），第二天上班看结果
- **每日冒烟**：工作日早上 8 点执行主链路流程（`0 8 * * 1-5`）
- **发布后验证**：配合 Jenkins 部署完成后的固定延迟触发，或直接用 [CI 回归测试集](../integration/regression.md)（接口 + UI 混合编排）

::: tip 与执行记录的关系
定时任务每次到点触发的执行，都会出现在[执行记录](./executions.md)里，可查看每步截图与回放。
:::
