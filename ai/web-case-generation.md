# AI 用例生成

> 根据需求文档 + 自定义提示词，生成云效格式 Web 功能测试用例，导出 Excel 可直接导入云效。

## 功能介绍

「AI 用例生成」是一个独立页面，从平台门户首页的「AI 用例生成」卡片进入。它解决一个痛点：**QA 写 Web 功能测试用例费时费力**--现在粘贴需求文档，选个提示词，AI 自动生成完整的测试用例（标题/前置条件/步骤/预期/优先级/标签），导出的 Excel 直接能导入云效。

![AI 用例生成页面](/screenshots/zh/ai_case.png)

与 [AI 自动测试](./auto-test.md) 的区别：

| | AI 用例生成（本页） | AI 自动测试 |
|---|---|---|
| 用例类型 | Web 功能测试用例（文档型） | 接口测试用例（API 型） |
| 输入 | 需求文档文本 | 代码 diff + 文档 + Swagger |
| 输出 | 云效格式 Excel（10 列） | 落 test_cases 表的接口用例 |
| 导出 | Excel 导入云效 | 平台内执行 |

## 两个功能区

页面侧边栏有三个导航项：

### 📝 提示词管理

管理可复用的提示词模板。每个模板包含名称、描述、模板内容（含 `{变量}` 占位符）。模板存入数据库的 `prompt_templates` 表（`category = case_writing`）。

**可用变量**（生成时自动替换）：

| 变量 | 含义 |
|------|------|
| `{requirement}` | 用户粘贴的需求文档 |
| `{case_types}` | 用例类型（如功能测试） |
| `{count}` | 生成数量 |
| `{coverage_checklist}` | 用例覆盖要求清单（系统管理，可编辑） |

操作：新建、编辑、删除。首次使用时内置一个「默认-Web功能用例生成」模板。

### 🚀 AI 用例生成

1. **选择提示词**：从下拉框选一个已管理的提示词模板（默认用内置模板），可点「预览」查看内容
2. **设固定规则**：配置自动套用到每条用例的固定值--负责人（如 luis）、类型（如功能测试）、生成数量上限（最多 100）；勾选哪些列留空（目录/关联工作项/标签默认留空）。这些不用在提示词里写
3. **粘贴需求文档**：把需求文档或功能描述粘贴到文本框，也可点「上传 MD 文件」直接读取 `.md`/`.markdown`/`.txt` 文件内容（浏览器本地读取，不上传服务器，限 5MB）
4. **编辑覆盖清单**：内置了 7 条通用用例覆盖要求，可增删改，生成时自动拼进提示词
5. **点「生成用例」**：创建后台异步任务，页面自动跳转到「结果记录」标签页
6. **自动轮询**：结果记录页每 3 秒自动刷新任务状态（等待中 / 生成中 / 已完成 / 失败），无需手动刷新
7. **完成后预览**：任务完成后点击「预览」查看生成的用例表格，每条用例可编辑（标题/步骤/预期/优先级/标签）
8. **下载 Excel**：批次需先通过[用例评审](./web-case-review.md)（全部用例 approved）才能下载，未通过时按钮置灰
9. **删除记录**：可删除不需要的生成记录

#### 异步生成流程

```
点击「生成用例」
    ↓
创建后台任务（状态=等待中）→ 页面跳转到「结果记录」标签页
    ↓
后台任务执行（状态=生成中）→ 页面每 3 秒自动轮询状态
    ↓
AI 生成完成（状态=已完成）→ 可预览 / 下载 Excel / 删除
    ↓
若失败（状态=失败）→ 显示错误信息，可删除记录后重试
```

::: tip 生成数量上限
「生成数量上限」最多可设 100 条。AI 会根据需求文档的覆盖度灵活生成，不必凑满上限数量。
:::

#### 固定规则

固定规则让用户不用每次在提示词里重复写"负责人=luis、类型=功能测试、三列留空"这些约定。生成后系统自动把固定值填到每条用例的对应字段，覆盖 AI 的输出。

优先级划分标准（P0-P3）已内置在默认提示词模板里，AI 会按这个标准给每条用例定优先级。

#### 覆盖清单

内置 7 条通用覆盖要求（可编辑），生成时自动拼进提示词的 `{coverage_checklist}` 变量位置：

1. 核心业务流程的正向路径覆盖
2. 必填字段校验、格式校验、边界值测试
3. 异常场景：网络错误、并发操作、权限不足
4. 列表/分页/筛选/搜索/排序功能
5. 新增/编辑/删除/状态流转操作
6. 弹窗/确认框/提示信息验证
7. 多端兼容、多语言、数据降级等边界场景

### 📋 结果记录

每次生成任务完成后，记录自动保存在侧边栏「结果记录」页卡里。可查看历史记录（名称/状态/用例数/时间）、预览用例、下载 Excel、删除记录。每条批次还可配置评审人，走「AI 评审 + 人工投票」流程，详见 [用例评审](./web-case-review.md)。

## 云效格式说明

导出的 Excel 有 10 列，与云效测试用例导入模板完全一致：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 标题 | 用例标题 |
| B | 目录 | 项目名/模块名 |
| C | 负责人 | 填写的负责人 |
| D | 前置条件 | 执行前需满足的条件 |
| E | 步骤描述 | **多行文本**，每行一个步骤（`\n` 分隔） |
| F | 预期结果 | **多行文本**，每行对应一个步骤的预期（`\n` 分隔，行号与 E 对应） |
| G | 关联工作项 | 留空（在云效里关联） |
| H | 优先级 | P0/P1/P2/P3 |
| I | 类型 | 功能用例/性能用例/接口用例 |
| J | 标签 | 逗号分隔 |

**关键**：步骤描述（E）和预期结果（F）是多行文本，每行一个步骤，两列行号一一对应。这是云效的格式要求，提示词里已明确约束 AI 这么输出。

## 导入云效

1. 在 AI 用例生成页面生成并导出 Excel
2. 打开云效 -> 测试管理 -> 测试用例 -> 导入
3. 选择导出的 Excel 文件，按云效提示完成导入

## 数据存储

- **提示词模板**：`prompt_templates` 表（`category = case_writing`），按用户隔离
- **生成的用例**：`web_test_cases` 表（字段对齐云效 10 列 + 管理字段，预留）
- **生成记录**：`case_export_records` 表（名称/状态/用例数/用例数据JSON/错误信息/模板ID/用例类型/数量上限/时间），支持历史查看 + 预览 + 下载 Excel + 删除

## 前置条件

- 需先在 [AI 配置](./model-config.md) 页面配置好 AI 模型（默认 Ollama 零配置可用）
