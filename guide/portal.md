# 门户首页

登录成功后，平台首先展示的是**门户首页**（`home.html`）。这是一个亮色企业风格的统一入口页，用卡片把平台的各大功能模块组织在一起，用户点击卡片即可进入对应工作台。

![门户首页](/screenshots/zh/home.png)

普通用户可见 **5 张卡片**，超级管理员（super_admin）额外可见 **监控中心** 和 **空间管理** 两张卡片，共 **7 张**。

## 空间选择与切换

平台按**工作空间**隔离数据（详见 [空间管理](./space-management.md)）：

- **首次登录**：首页会自动弹出空间选择门禁，选择所属空间后才能进入
- **日常切换**：页面右上角有**空间切换器**，点击可展开空间列表，选择后页面自动刷新、全部数据切换到目标空间
- **成员管理**：右上角的「👥 成员」按钮打开成员弹窗，空间管理员（owner / admin）可在此搜索用户、添加成员、分配角色

![空间切换器与成员入口](/screenshots/zh/space_switcher.png)

## 页面布局

门户首页采用浅色背景 + 白色卡片设计，每张卡片带有顶部彩色强调条和悬停升起效果。布局响应式，大屏 3 列、中屏 2 列、小屏 1 列。

## 入口卡片

### 普通用户卡片（5 张）

| 卡片 | 图标 | 跳转目标 | 说明 |
|------|------|---------|------|
| **产品文档** | 📖 | `/docs/` | 本文档站，完整使用手册与 API 参考，中英双语 |
| **AI 配置** | AI | `/static/ai_config.html` | 统一管理全平台 AI 模型，支持 Ollama / DeepSeek / 智谱 / Claude 等，默认本地零配置可用 |
| **AI 用例生成** | ✨ | `/static/ai_case.html` | 需求文档 -> 云效格式测试用例，自定义提示词，一键导出 Excel 导入云效 |
| **接口自动化** | API | `/static/index.html` | 接口测试主控台：Swagger 导入、用例管理、JMeter 压测、Mock 服务、流程编排、CI/CD 定时任务 |
| **UI 自动化** | UI | `/static/ui_index.html` | UI 测试工作台：流程编排、元素库、AI 驱动浏览器执行、可视化测试报告 |

### 超级管理员专属卡片（额外 2 张）

| 卡片 | 图标 | 跳转目标 | 说明 |
|------|------|---------|------|
| **监控中心** | 📊 | `/static/admin_monitor.html` | 超管专属只读面板：用户概览、操作时间线、资源生命周期、会话视图 |
| **空间管理** | 🏢 | `/static/space_admin.html` | 管理多工作空间：创建空间、成员管理、角色分配（owner / editor / viewer） |

## 使用建议

- **新用户**：从「产品文档」卡片开始，5 分钟快速上手了解平台全貌
- **首次配置 AI**：先进入「AI 配置」卡片，配置模型后再使用各 AI 功能
- **日常接口测试**：直接进入「接口自动化」卡片，这是最常用的工作台
- **Web 用例编写**：进入「AI 用例生成」卡片，上传需求文档生成云效格式用例
- **UI 自动化**：进入「UI 自动化」卡片，编排浏览器操作流程

## 各工作台主题

平台所有子页面统一采用**紫色主题**（主色 `#7c3aed` / `#6d28d9`），与门户首页的亮色风格保持一致的视觉体系。

- 接口自动化工作台（`index.html`）：紫色侧边栏 + 白色内容区
- UI 自动化工作台（`ui_index.html`）：紫色渐变侧边栏
- AI 配置页（`ai_config.html`）：紫色主题配置面板
- AI 用例生成页（`ai_case.html`）：紫色主题三栏布局
