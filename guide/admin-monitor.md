# 监控中心（超管）

监控中心是**超级管理员（super_admin）**专属的只读面板，用于跨用户全局监控平台运行情况。普通用户看不到入口。

::: tip 前置条件
账号需具备 `super_admin` 角色。如何设置见 [安装部署 → 用户角色与超管](./installation.md#用户角色与超管)。
:::

## 访问入口

以超管身份登录后，平台**首页（门户页）**会显示一张 **🛡️ 监控中心** 卡片，点击即进入监控中心独立页面。普通用户登录时首页不显示这张卡片。

![监控中心（超管专属）](/screenshots/zh/admin_monitor.png)

> 此外，超管登录后所有业务页面（测试用例、项目、批次等）看到的都是**全部用户**的数据（不按用户隔离），对自己数据可正常操作，对他人数据只读。

## 四个视图

### 1. 用户概览

列出**全部用户**及活跃度统计：

| 列 | 含义 |
|----|------|
| 用户 | 显示名 + 登录名 |
| 角色 | 超管 / 普通 |
| 状态 | 启用 / 禁用 |
| 操作数 | 该用户的操作日志总数 |
| 批次数 | 该用户创建的 AI 用例生成批次数 |
| 最近活跃 | 最后一次操作时间 |
| 创建时间 | 账号创建时间 |

点击任意一行 → 自动跳转到该用户的「操作时间线」。

### 2. 操作时间线

选定某位用户后，按时间倒序展示其**全部操作记录**（生成用例、评审、导出、配置评审人等）。每条操作显示：动作描述、模块、HTTP 方法、状态码、时间。这是追踪「某个用户做了什么」的视图。

### 3. 资源生命周期

查看**单个资源的完整生命周期**——支持「批次」和「用例」两种范围：

- 下拉选择某个生成批次（或直接输入用例 ID）
- 系统合并并按时间排序展示该资源的全部事件：
  - **创建事件**（批次生成 / 用例创建）
  - **评审记录**（AI 评审 + 人工投票，含完整 vote_round 审计链、驳回后 AI 自动重写）
  - **相关操作日志**（编辑、导出、配置评审人等）

适合排查「这条用例/这个批次是怎么走到当前状态的」。

### 4. 会话视图

按**登录会话**对操作日志分组。每个会话对应用户的一次登录后的连续操作：

- 每次登录会生成一个新的 `session_id`（前端自动生成并随请求携带）
- 会话卡片展示：用户、操作数、起止时间、前几条动作摘要
- 点击卡片 → 展开该会话的完整动作序列

历史日志（启用本功能前）没有 session_id，不会出现在会话视图中。

## 只读边界

监控中心是**纯只读**的：

- 所有 `/api/admin/*` 接口仅查询，不写任何业务数据。
- 超管**不能**修改 / 删除他人资源——现有写接口的归属校验（`资源属于你才能改`）依然生效，超管改他人数据会被拦截。
- 超管对自己创建的数据，仍走正常流程（他本身也是一个普通用户）。

## 操作日志全覆盖

监控中心的数据基础是平台既有的**操作日志系统**：每一次写操作（POST / PUT / DELETE / PATCH）都会被自动记录（含用户、模块、动作、参数、IP、会话）。超管在「操作日志」页面也能直接看到**全员**的日志（普通用户只能看自己的），与监控中心互补。
