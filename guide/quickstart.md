# 5 分钟快速上手

本篇带你跑通平台的完整主流程：登录 → 创建项目 → 导入 Swagger → 生成用例 → 执行 → 看报告。跟着 6 个步骤走完，你就能掌握平台 80% 的日常用法。

前置条件：平台已经部署完成并可通过浏览器访问。如果还没有环境，请先看 [安装部署](./installation.md)。

## 第 1 步：登录平台

打开浏览器访问平台地址，未登录会自动跳转到登录页。首次使用先注册账号，已有账号直接登录。

登录成功后，平台会先要求**选择工作空间**——首次访问会自动弹出空间选择门禁，选择你所属的空间后才能进入门户；之后可随时通过页面右上角的切换器更换空间。详见 [空间管理](./space-management.md)。

![首次登录：选择工作空间](/screenshots/zh/space_gate.png)

进入**门户首页**，展示入口卡片（普通用户 5 张，超管 7 张）（产品文档 / AI 配置 / AI 用例生成 / 接口自动化 / UI 自动化）。点击「接口自动化」卡片进入接口测试主控台，默认展示仪表盘，显示用例数、测试套件数、报告数、通过率四张统计卡片，以及「快速开始」四步引导。

![仪表盘](/screenshots/zh/dashboard.png)

## 第 2 步：创建项目与模块

平台按 **项目 → 模块 → 用例** 三层组织测试资产。先在左侧导航的任意管理页面（如「测试用例」）新建项目，再在项目下新建模块。

模块通常对应一个业务子系统或一组相关接口，例如 `用户中心`、`订单服务`。后续从 Swagger 导入接口时，可以按 tag 自动创建模块，也可以手动指定归属。

::: tip 命名建议
项目用业务线命名（如 `电商前台`），模块用服务命名（如 `用户服务`）。这样后续在执行测试时，按模块筛选一目了然。
:::

## 第 3 步：导入 Swagger

左侧导航 → **数据准备 → Swagger 解析**。

![Swagger 解析](/screenshots/zh/swagger.png)

操作步骤：

1. 在输入框填写 Swagger / OpenAPI 文档的 URL（例如 `http://your-service/v2/api-docs` 或 `/v3/api-docs`），也可以直接粘贴文档原文
2. 点击「解析」按钮，平台自动识别所有接口路径与方法
3. 选择目标**项目**和**模块**（支持按 tag 自动创建模块）
4. 勾选需要导入的接口，可全选 / 反选
5. 点击「生成测试用例」

生成完成后，用例会出现在「测试用例」页面，按模块分组。

::: warning 文档要求
Swagger 文档需要是标准的 OpenAPI 2.0 / 3.0 格式。如果接口缺少参数定义，生成的用例参数会为空，后续需要手动补齐或用 [AI 生成参数](../ai/param-generation.md)。
:::

## 第 4 步：配置全局参数

绝大多数接口都需要鉴权。左侧导航 → **测试管理 → 全局参数**，新建一条公共参数：

| 字段 | 示例值 |
|------|--------|
| 参数名 | `Authorization` |
| 值 | `Bearer eyJhbGciOi...` |
| 位置 | header |
| 作用域 | global |

配置后，所有测试用例的请求头会自动带上这个 Token，无需逐个用例配置。在用例中也可以用 `${Authorization}` 引用。

::: details 全局参数能配什么
除了鉴权 Token，常见的全局参数还有：`base_url`（环境地址）、`X-Tenant-Id`（租户头）、公共版本号等。详细用法见 [全局参数](../api-testing/global-params.md)。
:::

## 第 5 步：执行测试

左侧导航 → **执行与结果 → 执行测试**。

![执行测试](/screenshots/zh/execute.png)

操作步骤：

1. 选择**项目**
2. 选择**模块**（支持搜索、多选）
3. 选择**执行模式**（默认串行，保护被测系统；环境够强时可切并行）
4. 填写**基础 URL**（会自动拼接到每个用例的请求路径前，例如 `http://test.example.com`）
5. 可选：勾选「启用 Mock 数据」，用 Mock 规则替代真实接口
6. 点击「开始执行」

执行过程中可以实时看到进度条和每个用例的通过 / 失败状态。多个模块各自独立分栏展示结果。

## 第 6 步：查看报告

执行完成后自动跳转或进入左侧导航 → **执行与结果 → 测试报告**。

![测试报告](/screenshots/zh/reports.png)

报告页面提供：

- **报告列表**：按时间倒序，展示通过率、耗时、执行人
- **查看详情**：进入 HTML 报告页，包含每个用例的请求 / 响应报文、断言结果、响应时间
- **导出 Excel**：把用例级结果导出为表格，方便回归对齐
- **下载 Markdown**：把报告嵌入到项目文档或 Wiki
