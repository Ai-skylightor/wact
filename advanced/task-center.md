# 任务中心

任务中心（Task Center）是平台所有**后台异步任务**的统一入口。当某项工作量大到不能"点一下立即出结果"时——例如一次性给 50 个接口生成异常用例、批量生成测试参数——平台会把它丢到后台异步执行，执行过程和结果汇总都集中在任务中心。

![任务中心](/screenshots/zh/tasks.png)

## 任务类型

当前任务中心主要管理以下两类后台任务：

| 任务类型 | 触发入口 | 典型耗时 |
|---------|---------|---------|
| **AI 批量生成参数** | 测试用例页 → 选中用例 → AI 生成参数 | 几秒到几分钟，取决于用例数量与模型响应速度 |
| **AI 异常场景生成** | 测试用例页 → 选中用例 → 生成异常场景 | 较长，每个用例通常生成 5-10 条异常用例 |

任务以**异步**方式执行：你提交后可以继续在平台上做别的事，不用守着等结果。完成后任务中心左侧导航的角标数字会刷新，提醒你回来查看。

## 界面布局

进入 **AI 功能 → 任务中心**，看到的是一个时间倒序排列的任务列表：

| 列 | 含义 |
|----|------|
| **任务名称** | 自动生成，例如"AI 异常场景生成 - 登录用例" |
| **类型** | 任务类型（参数生成 / 异常场景 / 其他） |
| **状态** | 进行中 / 已完成 / 已失败 |
| **进度** | 完成数 / 总数，例如 `8 / 12` |
| **创建时间** | 任务提交时刻 |
| **操作** | 查看详情 / 清除 |

::: tip 角标实时刷新
左侧导航的"任务中心"图标上有一个角标数字，表示当前未查看的已完成任务数。每 5 秒自动轮询刷新，正在进行中的任务也会同步显示最新进度。
:::

## 查看任务详情

点击任务行的「查看详情」，进入任务详情页：

- **任务概览**：总用例数、成功生成数、失败数、平均耗时
- **成功列表**：每个 AI 生成的用例 / 参数项，附带 AI 推理的依据
- **失败列表**：失败的用例及错误原因（如 AI 不可用、超时、用例 schema 不完整等）
- **耗时分布**：可视化展示哪些用例生成耗时最长，方便定位模型性能瓶颈

## 异常用例审批工作流

AI 生成的异常用例**默认不直接启用**，而是进入一个轻量审批流程，避免低质量用例污染执行批次。

### 三种状态

| 状态 | 含义 | 后续动作 |
|------|------|---------|
| **待审（Pending）** | AI 生成完毕，等待人工审核 | 测试工程师逐条 / 批量审核 |
| **通过（Approved）** | 审核通过，纳入正常执行批次 | 用例变为 `enabled`，参与执行 |
| **驳回（Rejected）** | 审核未通过（无意义 / 误判 / 重复） | 用例被禁用或归档，不执行 |

### 操作步骤

1. 在任务详情页的「成功列表」中，逐条查看 AI 生成的异常用例
2. 评估每条用例的业务合理性：
   - **合理且有价值** → 点「通过」
   - **不合理或重复** → 点「驳回」
   - **可批量操作** → 多选后点「批量通过 / 批量驳回」
3. 通过的用例会出现在测试用例列表中并自动启用，可立即在「执行测试」里跑
4. 审批完成后，对应任务可以从列表中清除

::: tip 审批时关注哪些点？
不是所有 AI 生成的异常用例都有价值，重点保留这几类：

- **必填参数缺失**：业务上确实应该返回错误码的
- **边界值**：空字符串、超长字符串、0、负数、null
- **格式错误**：手机号少一位、邮箱少 `@`、日期格式错乱
- **类型混淆**：字符串字段传数字、数组字段传对象

可以剔除的：与已有用例完全重复、AI 误判把合法参数当成异常、纯随机字符的"垃圾用例"。
:::

## 清理任务历史

任务列表会随着时间不断累积。平台提供清理机制：

- **清除已完成**：移除所有 `已完成` 状态的历史任务（保留执行记录本身）
- **清除已失败**：移除所有 `已失败` 状态的任务
- **清除全部**：清空任务中心，谨慎使用

清除只删除任务记录本身，**不会删除** AI 已经生成并入库的用例 / 参数。已通过审批的用例仍然保留在测试用例列表中。

::: warning 任务记录 ≠ 测试报告
任务中心记录的是"AI 帮你生成了什么"，不是"测试跑出了什么结果"。要看测试执行结果，请到 **执行与结果 → 测试报告**。
:::

## 常见问题

::: warning 任务一直卡在"进行中"怎么办？
可能原因：

1. **AI 服务不可用**：检查右上角 AI 模型徽章是否绿色，模型是否在线（Ollama 服务在跑 / API Key 有效）
2. **任务量大**：批量生成 50+ 用例本来就需要几分钟，看进度条 `8/50` 在动就是正常的
3. **后端进程卡死**：清除任务后重新触发一次；若仍卡住，联系运维检查后端日志

:::

::: tip AI 生成的异常用例质量参差怎么办？
1. **更换更强的模型**：到 AI 配置页切换到参数更大的模型（如 qwen3:14b 替代 qwen3:7b）
2. **完善用例描述**：在测试用例的"描述"字段写清楚业务意图，AI 推断会更准
3. **关联 Swagger**：导入接口的 Swagger 定义，AI 能读到完整的参数约束
4. **走 Few-Shot 反馈**：驳回时填写驳回原因，平台会把样本反馈给 AI 做下一次优化
:::
